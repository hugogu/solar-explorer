# 太阳系 · 3D 交互星图

一个用真实星历驱动的太阳系 3D 科普网站。天体按实际轨道与自转运行，可以把时间拨到任意时刻，
查看任意地点的日出日落，并预报未来的日食与月食——包括在本地能看到什么。

![浏览器 · 手机 · 触屏](https://img.shields.io/badge/-桌面%20%7C%20移动%20%7C%20触屏-1f2937)

## 功能

- **完整的太阳系结构**：太阳、八大行星、8 颗矮行星、29 颗主要卫星、8 颗著名彗星，
  以及小行星带（含柯克伍德空隙）、木星特洛伊群、柯伊伯带、离散盘与奥尔特云内缘。
  每一类天体都可以在左侧列表的分类节点上单独开关显示。
- **真实位置模拟**：任意时刻的天体位置与自转角都由星历计算，而不是动画循环。
  时间可正放、倒放，速度从实时到「10 年/秒」。
- **每个天体自己的事件**：「事件」面板跟随当前选中的天体。地球给出完整历表——日出、
  上中天、日落、昼长、三种曙暮光、月出月落、月相与日月食；其他天体回答同样的问题：
  站在它上面时太阳何时升落、它的一个太阳日有多长（火星 24.66 小时、月球约 29.5 天、
  水星 176 个地球日），以及它下一次过近日点、冲、合或大距是什么时候。
  极昼极夜也会正确标出。
- **定位与标记**：选择或输入观测点后，镜头会转到能看见该点的位置，并在星球表面标出它；
  镜头随星球自转跟随该点，直到你自己拖动画面为止。
- **日食与月食预报**：列出未来的日月食，给出类型、食甚时刻、食甚点坐标，
  以及在你所选地点的**本地环境**——食分、遮挡比例、初亏/食甚/复圆时刻。
- **在 3D 中观看日食**：月球投在地球上的本影与半影是按真实几何逐像素计算的，
  木卫一投在木星上的影子同样如此。
- **本影轨迹**：日食进行中时，地球表面会画出真实宽度的食带、当前本影位置和半影边界，
  并随时间在地表上扫过——食带随地球自转，本影沿着它移动。附带食带宽度、
  最长中心食时长与各阶段时刻。
- **地表视角**：站在地球（或火星、月球）表面看天空，带真实的大气散射、
  地平线、方位罗盘与曙暮光变化。
- **跨设备**：桌面用鼠标与键盘，手机与平板用单指旋转、双指缩放，界面在窄屏下自动折叠为底部抽屉。

## 快速开始

```bash
npm install
npm run dev
```

打开 <http://localhost:5173>。

可选：下载地球与月球的真实影像贴图（公有领域的 NASA 影像，来自 three.js 仓库）。
不执行也能正常运行——所有天体都有程序化生成的表面。

```bash
npm run fetch-textures
```

生产构建：

```bash
npm run build && npm run preview
```

## 操作

| 操作 | 说明 |
| --- | --- |
| 拖动 / 单指滑动 | 旋转视角 |
| 滚轮 / 双指捏合 | 缩放 |
| 点击天体或标签 | 选中并跟随 |
| 空格 | 播放 / 暂停 |
| `[` `]` | 减速 / 加速 |
| 方向键或 `WASD` | 旋转视角 |
| `Q` `E` 或 `+` `-` | 缩放 |
| `1`—`9` | 依次切换到八大行星与冥王星 |
| `0` | 回到太阳 |
| `R` | 反转时间方向 |
| `L` / `O` | 开关标签 / 轨道 |
| `Esc` | 取消跟随，退出地表视角 |

## 数据来源与精度

计算全部在浏览器内完成，没有后端，也不请求任何天文接口。

| 项目 | 方法 | 精度 |
| --- | --- | --- |
| 太阳位置 | 截断的 VSOP87D 地球级数 + FK5 修正 + 章动 + 光行差 | 几角秒 |
| 月球位置 | ELP-2000/82 截断级数（Meeus 第 47 章，60+60 项） | 经度约 10″，距离约 20 km |
| 行星位置 | JPL《主要行星近似位置》开普勒根数 | 1800—2050 年内约 1 角分 |
| 地球自转 | 视恒星时 + 岁差 + 章动 | 与日出日落计算完全一致 |
| 其他天体自转 | IAU/WGCCRE 旋转要素（含月球天平动项） | 度级 |
| 日出日落 | 对太阳高度过 −0.833° 求根 | 与天文年历相差 1 分钟以内 |
| 日月食 | Meeus 第 54 章周期项；本地环境由日月视圆面的地平几何直接计算 | 食甚时刻通常优于 1 分钟 |
| 食带轨迹 | 逐点求解影锥轴与地球的交点；中心食（全食带／环食带）时长在每个点上直接测量，而非用宽度除以速度 | 时长与星表相差 3% 以内，全食带宽度 1—5% |
| 伽利略卫星 | Meeus 第 44 章真实平黄经 | 相位真实 |

**已知的近似**：食带宽度未做月面地形改正（星表用月球边缘的真实山脊剖面）。
掠入射的日食（如 2026-08-12、2026-02-17）因为影锥几乎与地表相切，"宽度"的定义
本身就不唯一，本站给出的横向宽度会明显大于星表值；但这些情况下的中心食时长
仍与星表相差在 3% 以内。日全食与日环食用同一套几何判据，环食带同样会画出。
除木星四大卫星外，其余卫星与矮行星的轨道要素（半长轴、偏心率、倾角、
周期）为实测值，但历元时刻的轨道相位为估计值，因此它们在轨道上的具体位置是示意性的。
小行星带、柯伊伯带等群体按真实的轨道分布统计生成，不对应真实编号天体。
界面中对这些近似都有明确标注。

验证方式见 `tests/`：月球位置对照 Meeus 例题 47.a，五个二分二至时刻对照公布值，
北京冬夏至日出日落对照天文年历，2023—2027 年的 15 次日月食对照已公布星表。

```bash
npm test
```

## 项目结构

```
src/
  astro/      纯计算：时间尺度、坐标系、轨道、太阳、月球、行星、自转、升落、日月食
  data/       天体目录：物理参数、轨道参数与科普内容
  app/        模拟状态、时间控制、应用状态
  render/     three.js 场景：天体、轨道、星空、小天体群、相机、程序化贴图
  ui/         界面面板（无框架，原生 DOM）
tests/        对照公布值的验证测试
scripts/      可选的贴图下载脚本
```

`src/astro/` 不依赖 three.js，也不依赖浏览器，因此可以在 Node 中直接测试。
渲染层不做任何天文计算，只消费 `Simulation` 给出的位置与姿态。
